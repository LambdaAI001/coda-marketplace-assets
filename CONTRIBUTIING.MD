# Contributing to Coda

Thank you for your interest in contributing to Coda! Coda is an open-source project released under the **MIT License**.

This repository (`coda-marketplace-assets`) serves as the public coordination center, issue tracker, and feature roadmap discussion hub.

---

## How You Can Contribute

### 1. Reporting Bugs
- Search existing issues before creating a new one to avoid duplicates.
- Use our [Bug Report Template](https://github.com/LambdaAI001/coda-marketplace-assets/issues/new?template=bug_report.md).
- Include reproducible code examples, extension logs from the VS Code Output channel (`Output > Coda AI`), and OS / VS Code version details.

### 2. Proposing Superpowers & Enhancements
- Check the [Feature Requests](https://github.com/LambdaAI001/coda-marketplace-assets/issues?q=is%3Aissue+label%3Aenhancement) or start a discussion.
- Clearly describe the developer workflow problem and why existing tools or extensions fall short.
- Use the [Feature Request Template](https://github.com/LambdaAI001/coda-marketplace-assets/issues/new?template=feature_request.md).

### 3. New Model Providers & Benchmark Evals
- Suggest new model providers, local inference runners (vLLM, Ollama, LM Studio), or cloud API endpoints.
- Share benchmark results, speed metrics, or tool-calling accuracy observations on real-world codebases.

### 4. Improving Documentation
- Documentation PRs for guides, troubleshooting walkthroughs, and provider setup manuals are always welcome.

---

## Security Disclosures

If you discover a security vulnerability or secret leakage risk in Coda:
- **Do not open a public issue.**
- Submit a private report via [GitHub Security Advisories](https://github.com/LambdaAI001/coda-marketplace-assets/security/advisories/new) or refer to [SECURITY.md](SECURITY.md).

---

## Community Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for everyone, regardless of experience level, background, or identity. Please be respectful and constructive in all interactions.
